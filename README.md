# Remote MCP Server

## Overview
A remote MCP server built using FastMCP.

## Features
- Add two numbers
- Generate random numbers
- Server information resource

## Tech Stack
- Python
- FastMCP
- MCP
- HTTP
- Uvicorn

## How to Run

uv sync

fastmcp run main.py --transport http --host 0.0.0.0 --port 8000

## MCP Inspector

Server can be tested using MCP Inspector.
